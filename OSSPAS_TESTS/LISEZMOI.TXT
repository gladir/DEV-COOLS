Tests de la ligne A de l'emulateur (OSSPAS.PAS)
===============================================

Chaque test genere un vrai programme .PRG 68000 (en-tete GEMDOS, table de
relocation, appels $A000..$A00F, Pterm), le fait executer par l'emulateur puis
relit l'ecran logique (OSSDUMPSCR) et le compare a un modele de reference ecrit
en Python (modes d'ecriture, masques, motifs, operations BITBLT, effets de texte...).

  fpc -Mfpc OSSPAS.PAS            # produit ./OSSPAS
  Xvfb :99 &                      # l'emulateur ouvre une fenetre
  export DISPLAY=:99 OSSPAS_BIN=./OSSPAS
  python3 OSSPAS_TESTS/la_pixel_ligne.py          # etc., un script par famille

Fichiers : la_pixel_ligne (A001-A004), la_motif_rect_polygone (A004-A006),
la_bitblt (A007), la_textblt + la_textblt_echelle (A008), la_lutin_copie_germe
(A00C-A00F). La ligne "FAILS []" en fin de sortie signifie : aucun ecart.

Les memes tests tournent sur l'emulateur de DEVPAC.PAS : export OSSPAS_EMU=devpac (utilise
/EMUL:prog.prg /NOGEM /SCR: /DUMP: de DEVPAC.PAS, sans interface graphique).

Programmes assembleur reels (assembles par DEVPAC.PAS, en mode batch) :
  la_programme_asm_texte.py     chaines affichees avec TEXTBLT en lisant l'en-tete de police
                                et la table des decalages, 12 lignes avec tous les effets
  la_programme_asm_graphique.py demonstration (lignes, rectangles a motifs, polygones, lignes
                                horizontales, BITBLT recouvrant, lutins, remplissage par germe)
  fpc -Mfpc DEVPAC.PAS ; export DEVPAC_BIN=./DEVPAC

Limite : les references sont ecrites d'apres la documentation de la ligne A, pas
mesurees sur un vrai Atari ST ; elles verifient la coherence et les proprietes
(positions, modes, masques, rotations), pas l'identite pixel a pixel avec le TOS.
