============================================================
  PYTHON3.PAS - Clone de la commande python3 (Python 3.8)
  Free Pascal (mode ObjFPC) - cible : Linux x86-64
  Executable : BINLINUX/PYTHON3
============================================================

  Compilation :
    fpc -Mobjfpc -Sew- -O2 -Xs PYTHON3.PAS -oBINLINUX/PYTHON3

  Remarque : le programme n'utilise ni classes, ni objets, ni methodes :
  uniquement des enregistrements (Record), des pointeurs et des
  procedures/fonctions. Unites employees : Dos, BaseUnix, Unix, Termio
  (ni SysUtils, ni Classes, ni Math, ni StrUtils, ni DateUtils). Il ne
  peut cependant pas etre compile avec Turbo Pascal 7 lui-meme (mode -Mtp
  impossible : Int64, AnsiString, tableaux dynamiques, plus de 64 Ko).

  LIMITES CONNUES
  ============================================================
  - Pas d'extensions C (_ctypes, sockets, ssl, sqlite3, ...).
  - Pas de multithreading preemptif (threading cooperatif).
  - Les signaux asynchrones ne sont pas delivres aux gestionnaires.
  - Les codecs multi-octets CJK (gbk, big5, shift_jis, ...) ne sont
    pas fournis.
  - Les SyntaxWarning emis a la compilation ne sont pas affiches.

  TODO 14 - ARCHITECTURE SANS CLASSE [IMPLEMENTE]
            Les objets Python (str, list, dict, fonctions, iterateurs,
            ...) sont des enregistrements dont les premiers champs sont
            communs (otag = genre, cls, idict, marques du ramasse-
            miettes) ; chaque genre a sa fonction de creation (AllocXxx).
            Les anciennes methodes sont des fonctions dont le premier
            parametre est l'enregistrement (ListInsert(l, i, v)). Les
            methodes virtuelles (MarkKids, IterNext, ObjNativeAttr,
            ObjNativeRepr, FreeObjMem) sont des distributeurs selon otag.
            Les exceptions utilisent try/except de Pascal ; Raise exige un
            objet : on leve l'adresse d'un enregistrement TXc dont le
            premier champ est le pointeur de classe de base du runtime
            (voir RaiseXc), les gestionnaires testent XcTag. Les erreurs
            d'execution du runtime (violation d'acces, memoire) sont
            converties par ErrorProc (RuntimeErrorToExc).
